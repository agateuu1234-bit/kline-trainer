# 切片一 P3a（冻结契约文本一致性）· 非程序员验收清单

**这一片做了什么（一句话）**：把两份「根级权威文件」里**跟现在的程序行为直接打架**的一条规则改写掉，把三处仍写「第 1 代」的版本引用改成第 2 代并各加一句过渡说明，然后加两条自动检查把这两件事钉住。

**为什么要做**：更早的一片改了程序算编号的方式 —— 除分钟线外，其它周期的编号**允许重复**（比如月线是 `0, 0, 17, 23`）。但两份权威文件仍写着「全周期严格递增」。这不是「文档不好看」，而是**日后任何照旧规则写的检查，会把每一个新产物都判死**。
