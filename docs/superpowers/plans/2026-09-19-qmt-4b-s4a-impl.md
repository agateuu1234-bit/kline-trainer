### Task 1 · 字节预算 + 单文件流式拷贝

**Files:** Create `backend/qmt_fetch.py`、`backend/tests/test_qmt_fetch.py`

**绑定契约条款：D3（源侧叶子非普通文件）、D7（逐块记账与回滚退还）**

**交付物**
- 三族互不相交的异常：候选失败 / 终止条件 / 路径逃逸（后者原样上抛）。
- 字节预算对象：事前 `stat` 早拒、逐块扣减、**退还**。
- 单文件流式拷贝：读源 → 流式 sha256 → 逐块扣账 → 写 `.part` → `fsync` → **对落地的 `.part` 重算并与源哈希比对**。

**必须产出的证据**（缺一不可，写进报告）
1. D3 的验收：**源侧 FIFO 与源侧 socket 各一档**；socket 那档另断言权限错误（`EACCES`，打桩造）**不**被归成 `fetch_missing_file`。
2. **变异坐实 D3 判别力**：把实现改成 `except OSError: raise StockCopyFailed("fetch_missing_file")` ——**必须有一档变红**。零红即判据无判别力，回头重构造。
3. D7 的验收：同一只股连续失败三次后预算剩余量与从未尝试过时**相同**；**且必须覆盖「拷到一半抛异常」那条路**（只测「文件缺失」会漏掉它）。
4. **变异坐实 D7 判别力**：把「本次已写字节」的记录从逐块累加改成「仅在拷贝函数成功返回后赋值」——退还那一档必须变红。
5. 落地复算不得是恒等式：构造「写出去的字节与读回来的不同」（打桩少写一段），断言判 `fetch_copy_hash_mismatch`。

### Task 2 · 幂等四象限判据

**Files:** Modify `backend/qmt_fetch.py`、`backend/tests/test_qmt_fetch.py`（追加，不改 Task 1 已有符号）

**绑定契约条款：D2（staging 目标非普通文件一律拒绝覆盖，符号链接除外）、D4 第 1 条（「相符」判据含 `S_ISREG`）**

**交付物**
- 四象限判据（manifest 有无记录 × 目标在不在），返回四个字面量之一。
- 「目标存在 / 相符」都由**调用方自己查 `stat.S_ISREG`**，不是 `except NotARegularFileError`。
- 非普通文件（**不含符号链接**）一律判拒绝覆盖，不按有无记录分叉。

**必须产出的证据**
1. R2-F3 回归钉：**同尺寸不同内容**必须判重拷，不得跳过。
2. D2 的验收：**目录与 FIFO 各一档**，且**必须构造「记录的 `bytes` 恰等于那个非普通对象的 `st_size`」**——否则测试是碰巧过的。
3. 符号链接叶子必须走路径逃逸（整次致命），**不得**落进拒绝覆盖那一档。
4. 判据对**任意坏输入**安全：记录字段缺失 / 类型不对 / 不可哈希类型，一律**拒绝**（抛清楚的错），**不是跳过**。
5. **变异**：①只比字节数不比哈希 ②非普通文件当成相符 ③坏记录「跳过」而非「拒绝」——各自**单独跑**（把邻居 deselect 掉），确认红的是**那一条**。

### Task 3 · 在途标记 + 单股事务编排

**Files:** Modify `backend/qmt_fetch.py`、`backend/tests/test_qmt_fetch.py`（追加）

**绑定契约条款：D1（两条路径的前置校验）、D4 第 2 条（任何有记录的格都要比对）、D5（不符即终止，比对早于落地）、D6（标记写下后只有两条出路）、D7（`committed_bytes` 累计语义）、D8（跳过由四象限承担）**

**交付物**
- `.inflight.json` 的**形状定义**（模块级常量 + 构造函数，S4b 将导入它）、写与删。
- 单股事务：四象限 → 拷 `.part` → **比对** → 写标记 → 两次 `os.replace` → 耐久 `fsync` → 按股提交 → 删标记。
- 失败/终止路径：删该股**两个** `.part`、退还预算、原样上抛。

**必须产出的证据**
1. 端到端正路：两 final 落地、无 `.part` 残留、无标记残留、`files` 恰 2 条、`pool_order` 一条锚点、`cursor` 推进、`committed_bytes` 含 staged export_log。
2. D1 的验收：次序互换与 code 不符**都必须被拒**，且**拒绝发生在写标记之前**——断言标记不存在、无 final 落地。
   **变异**：删掉前置校验，本档必须变红。
3. R37-F1 回归钉：一只股的 daily 缺失时，**1m 的 final 不许残留**（清理粒度是**股**不是文件）。
4. D5 的验收：本地坏 + 源等长换代 → 在写标记**之前**终止；标记未写、`.part` 无残留、`cursor` 未动、manifest 逐字节未变。
5. D4 第 2 条：**「有记录 × 目标不存在 × 源已换代」单独一档**（不只是重拷那一格）。
6. D6：标记写下后每一次 `os.replace` 时标记都必须在盘上。**变异**：把写标记挪到两次 replace 之后——本档必须变红（正路上看不出问题）。
7. 耐久：每次命名空间改动之后都要 `fsync` 其目录。**变异**：去掉 replace 之后的目录 `fsync`——必须变红，且**红的是这一条**（把邻居 deselect 掉单独跑）。
8. D7：`committed_bytes` 写 `旧值 + 本次真正写盘字节`；崩溃恢复第③档删记录时原值不动。
