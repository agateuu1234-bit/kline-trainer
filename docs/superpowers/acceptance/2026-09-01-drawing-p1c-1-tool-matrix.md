## 验收前的准备

- 必须装**开发调试版**（Debug 版），并带开关 `KLINE_SEED_FIXTURE=1` **冷启动一次**，往 App 里灌测试数据。
  - 不灌的话会报「训练组文件不存在」—— 那是测试环境没准备好，**不是本片的回归**。
  - 灌数据只在「训练组缓存 + 历史记录 + 未完成对局 + 设置」**四样都是初始状态**时才会执行；任何一样有数据就**静默跳过、不报错**。
  - 判断是否真的灌进去了，要看**前后差分**（训练记录条数从 0 变成有值、训练组缓存目录从空变成有文件），**不要只看「启动成功」**。
- App 已在运行时带开关启动**不起作用**（只是把它切到前台），必须先彻底结束进程再冷启动。
- 首次安装新签发的开发者证书后，需在手机上「设置 → 通用 → VPN 与设备管理」点一次**信任**，否则系统拒绝启动。

## 先认识画面（这些是本片之前就有的形态，不是本片改的）

- **进入画线**：训练页顶部、红色「结束」左边的**铅笔图标**。进入后「结束」会变成「退出」。
- **画线底栏**（从左到右）：「类型」、🔒 锁、🗑 垃圾桶、↩ 撤销、↪ 前进。
- **样式面板**（浮在 K 线上）分五组：
  - **线型**：3 个图标，**没有文字**。从左到右依次是 直线、射线、线段。
  - **线样式**：5 个图标（实线与四档虚线）。
  - **粗细**：5 个图标。
  - **颜色**：7 个彩色圆点 + 1 个「线色」。
  - **标注**：**有文字**，从左到右是「隐藏 / 显示 / 左 / 右」。
- 面板上另有一行：左边一个**横线图标** —— **蓝框 = 画线状态，灰框 = 选择状态，点它切换**；右边 ⇅ 把面板挪到上半区或下半区。
- ⚠️ **画线状态下点已有的线是选不中的**（设计如此）：画线状态里唯一会产生选中的是「刚画完那一下」。要操作旧线，先切到**选择状态**。

## 验收条目

| # | 动作 | 预期 | 通过/不通过 |
|---|---|---|---|
| 1 | 首页点「开始训练」或「继续训练」→ 点铅笔图标 → 在 K 线上没被面板遮住的地方，点 3 个不同高度 | 每点一下出现一条水平线；**刚画的那条处于选中状态** | ☐ 通过 ☐ 不通过 |
| 2 | 点面板上的横线图标切到**选择状态**（框变灰）→ 点第 1 条线把它选中 → 依次点一个别的颜色、一个别的粗细、一个别的线样式 | **被选中那条线**的颜色、粗细、虚实立刻跟着变；**另外两条不变** | ☐ 通过 ☐ 不通过 |
| 3 | 保持选中，看「线型」那一排的 3 个图标 | 左数第 1、2 个可以点；**左数第 3 个是灰的**，点了没有反应 | ☐ 通过 ☐ 不通过 |
| 4 | 点线型第 1 个图标 → 在「标注」那排点「左」→ 再点线型第 2 个图标 | 「左」变灰，且选中项**自动跳到「隐藏」**；「显示」**始终**是灰的 | ☐ 通过 ☐ 不通过 |
| 5 | 保持选中，依次：① 点 🔒 ② 再点 🔒 ③ 点 🗑，在「确定删除划线？」里点「删除」 ④ 点 ↩ ⑤ 点 ↪ ⑥ 再点 ↩ | ① 锁合上，样式面板与 🗑 一起变灰 ② 锁打开，两者恢复可用 ③ 这条线消失 ④ 线回来 ⑤ 又消失 ⑥ 又回来（**撤销只退一步**） | ☐ 通过 ☐ 不通过 |
| 6 | 点顶部「退出」离开画线 → 上滑回到桌面 → 从后台把 App 划掉 → 重新打开 | 首页主按钮是**「继续训练」**；点进去后 3 条线都在，**颜色、粗细、虚实和关掉之前一样** | ☐ 通过 ☐ 不通过 |
| 7 | 点红色「结束」→ 在「结束本局训练」里点「是」→ 在「本局结算」页点「确认」 | **不出现**「结算入账失败」；回到首页后，历史记录里多出这一局 | ☐ 通过 ☐ 不通过 |
| 8 | 在首页历史记录里点这一局 → 选「复盘」→ 点左上角的铅笔圆按钮 → 点「水平线」（按钮变成橙色「结束画线」）→ 在 K 线上点一下 → 点「结束画线」→ 点「结束」→ 选「保存」 | 能正常画出一条水平线。**复盘里没有样式面板，也没有锁 / 删除 / 撤销按钮 —— 这是本片之前就有的设计，不算不通过** | ☐ 通过 ☐ 不通过 |

> ⚠️ **第 6 条必须排在第 7 条之前**：第 7 条会把这一局结算掉，结算之后就没有「继续训练」可点，第 6 条也就无从验起。

- 契约版本变更（本片不 bump）。
